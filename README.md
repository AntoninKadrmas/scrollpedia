# The Scrollpedia

Web app build around https://www.edgechat.ai/api wich offers a lot of articles in markdown format. App lets user to swipe to explore new articles read articles in app, search for articles or filer the search and feed by category, and save favorite articles.

## GitHub Pages

Run `pnpm run deploy` to build the app and publish `dist` to the `gh-pages` branch.
The `--nojekyll` option creates `.nojekyll` in the publishing root so GitHub Pages
serves generated assets whose names start with `_`, including the `_slug` route chunks.
